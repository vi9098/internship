# 🧭 Find Me

**Find Me** is a modern, responsive, career discovery platform that helps students and early-career job seekers discover verified internships worldwide with premier focus and priority on **Government of India** ministries, regulators, and **State Governments**, alongside top private technology companies, research labs, and global institutions.

> **Made by Legislative** • Dedicated to transparent public service access and student career enablement.

## 🚀 Quick Start

### 1. Requirements
- Python 3.10+
- Install dependencies:
  ```bash
  pip install -r requirements.txt
  ```

### 2. Launch Find Me
From the project folder, run:
```bash
python run.py
```
This starts the backend server on `http://localhost:8000` and automatically opens the platform in your browser.

---

## 🧪 Running Automated Tests

Run the test suite:
```bash
python -m unittest backend/test_api.py
```

Validates:
- Indian Government and State Government sector filtering
- Official verification flags and "last updated" timestamps
- Priority boost scoring for Indian students targeting public service
- Skill Up catalog (Skill India, SWAYAM, NPTEL, Google, Microsoft, IBM, AWS, Salesforce, Meta, Cisco)
